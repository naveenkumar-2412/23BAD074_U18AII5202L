# Experiment 5: Interactive Dashboard Development

## Overview
This experiment focuses on creating an interactive dashboard using Power BI for exploratory data analysis and visualization of student performance data.

## Objective
- Design and develop an interactive dashboard using Power BI
- Visualize student performance metrics across different dimensions
- Enable dynamic filtering and drill-down capabilities
- Present insights through intuitive visual analytics

## Dataset
- **File**: `5.student_performance.csv`
- **Description**: Student performance data including test scores, assignments, attendance, and grades
- **Features**:
  - Student_ID
  - Department
  - Semester
  - Subject
  - Internal_Test1
  - Internal_Test2
  - Assignment_Marks
  - Attendance_Percentage
  - Final_Grade

## Tools Used
- **Power BI Desktop**: For dashboard creation and data visualization
- **Data Source**: CSV file containing student performance metrics

## Dashboard Components
The Power BI dashboard includes:
- Performance metrics by department and semester
- Test score distributions and trends
- Attendance vs grade correlation
- Subject-wise performance analysis
- Interactive filters and slicers

## Files
- **Dashboard/**: Contains the Power BI dashboard file (.pbix)
- **Data/**: Student performance dataset
- **Document/**: Experiment documentation and report

## How to Use
1. Open the `.pbix` file in Power BI Desktop
2. Explore the interactive visualizations
3. Use filters and slicers to analyze specific segments
4. Drill down into details for deeper insights
